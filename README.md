# 五十音 Kana Dojo

日文五十音練習，四種模式：

1. **羅馬拼音（看字 → 輸入羅馬字）** — 看到假名後輸入羅馬拼音（接受 shi/si、tsu/tu、wo/o 等寫法）。
   作答後（不論對錯）需按「下一題」才會換題；「下一題」平時為中性深灰，答錯時才轉為紅色。
2. **鍵盤輸入（聽發音 → 選假名）** — 聽發音後選出正確假名。鍵盤**每次出題都重新打亂**（不照 あいうえお 順序）且只放清音；
   濁音／半濁音／拗音以「清音 + 符號」組合輸入：先選 か 再按 ゛ 即成 が，き + ゃ = きゃ，不會一次列出所有字。
   上方「你選了」會顯示目前組合；若該字不需加符號，選好後按「檢查」即可提交。
3. **手寫（聽發音 → 手寫）** — 聽發音後在格子裡書寫，以本機筆順比對自動辨識；辨識不到時可自行核對答案。
   判定後（✓／✗）同樣需按「下一題」才會換題，不會自動跳題。
   寫完後按候選字**一次即視為確定**，立即判定對錯；沒選候選字則按「看答案」自行核對。
4. **讀音（看字 → 讀出聲音，語音評分）** — 顯示一個假名，按「錄音」讀出聲音，再用瀏覽器內建的語音辨識（ja-JP）比對：
   辨識結果與答案相同＝答對；辨識成別的字＝答錯（會記入錯題簿）；完全辨識不到＝「聽不清楚」，可再試一次（不計分、不記入錯題簿）。
   **練習時不會自動示範發音**，不確定讀音時可按「示範」聽標準讀音。此模式免費、不需 API key，但需要連網，
   且 **iPhone／iPad 的 Safari 不支援**——錄音鍵會顯示為灰色，請改用 Chrome 開啟本頁。

題庫選擇：**平假名／片假名／隨機混合／錯題簿**

- **隨機混合**：平假名與片假名混合出題，每題上方會標明是「ひらがな」還是「カタカナ」
- **錯題簿**：答錯的字會自動記錄（同一個字不重複），在錯題簿中答對就會自動移除。
  選擇「錯題簿」會**直接開啟管理清單**（不需再按「管理」）：可逐項勾選是否練習、✕ 刪除、手動加字、
  全選／全不選、清空；清單下方會顯示目前使用哪個模式練習，按「開始練習」只會出已勾選的字。
  **開啟清單期間不會出題、不會播放聲音**，按完「開始練習」才開始。
  每列會標示字類（例如「ひらがな · 濁音」），避免誤認。

語音：Google（預設）／Nanami 神經語音，可切換慢讀。
**靜音**：右上角（「重設」右邊）有喇叭圖示，按一次全站靜音（真人音檔與 TTS 一同靜音），
再按一次恢復並重播目前題目；設定會保留。音量大小請使用手機本身的音量鍵。
可選「拼音」提示：開啟後會在喇叭下方顯示羅馬字。

**假名表（溫習用）**：右上角文件圖示 → 開啟五十音表，清音／濁音／半濁音／拗音全部齊全；
表頂可切換 **平假名／片假名**，整版即時轉換（會記住上次選擇）；每格下方有羅馬字，
**按下即會讀出聲音**（依目前語音設定，靜音時不出聲）。

**字類（可選加練）**：`濁音`（が ざ だ ば）、`半濁音`（ぱ ぴ ぷ ぺ ぽ）、`拗音`（きゃ しゃ ちゃ …）
可逐項開關，預設全部關閉（即只練 46 個清音）。開啟後練習題庫、鍵盤與讀音都會包含該類字，平假名／片假名同步。
手寫模式亦有筆順範本（濁音＝原字＋゛、半濁音＝＋゜、拗音＝大字＋小字），
由 `tools/make_extra_templates.py` 以 46 個清音範本合成；範本載入失敗時仍可按「看答案」自行核對。

## 網頁版（PWA，可加入主畫面）

<https://alice-creator-lab.github.io/kana-dojo-dev/>

已是 PWA：第二次開啟會使用 service worker 快取，離線也能使用。iPhone／Android 用瀏覽器「加入主畫面」即近似原生 app。

## 平台

只提供網頁版（PWA）。Android APK 與 Capacitor 原生專案已移出本 repo；如需重新產出 APK，請參考上游 `sunhsieh/kana-dojo` 的歷史版本。

## 專案結構

```
index.html              # 全部 app 邏輯（單頁 vanilla JS）
kana-templates.json     # KanjiVG 筆順模板（46 平假名 + 46 片假名）
audio/g/*.mp3           # Google 日語語音
audio/n/*.mp3           # Nanami 神經語音
icons/                  # PWA / favicon 圖示
manifest.webmanifest    # PWA manifest
sw.js                   # service worker（離線快取）
tools/make_icons.py     # 產生網頁圖示
```
